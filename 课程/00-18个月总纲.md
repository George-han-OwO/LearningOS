## 章节制规则

每个主章节分为 5 个小任务：

1. 直觉：用日常语言说明“这是什么、为什么需要它”。
2. 公式：只引入本章必须的数学，并逐项解释符号。
3. 实验：运行代码，改变一个变量，观察结果。
4. 选择题：至少 5 题，覆盖概念、计算和判断边界。
5. 复盘：用自己的话回答“如果去掉这个部件会怎样”。

章节解锁建议：选择题不少于 80%，实验能运行，且能完成一题不看答案的解释题。
低于门槛时，AI 不直接判定失败，而是将错误归类为：概念混淆、计算错误、代码
错误、读题错误或记忆衰退，再布置对应补课。

## 毕业项目

完成一个小型中文或中英混合字符级语言模型：

```text
原始文本 → tokenizer → token id → embedding → attention/MLP
→ next-token logits → softmax 概率 → loss → gradient → 更新参数
→ 保存模型 → 输入提示词 → 逐 token 生成
```

毕业项目不追求和 DeepSeek 的规模相同，而是要求每一条数据流都能被解释、运行
和测试。DeepSeek-V4-Pro 的规模和硬件需求远超个人电脑，因此“手搓”目标是复现
机制，不是假装在本地训练 1.6T 模型。
