# AILearningOS · 18 个月 AI 学习课程

这套课程面向当前刚开始 AP 统计、还没有学微积分、编程和 AI 基础的学习者。
课程最终目标不是背诵术语，而是能够解释 DeepSeek-V4-Pro 的关键原理，并亲手
实现一个小型、可运行的语言模型。

## 使用方法

每个章节都按以下循环完成：

```text
学习目标 → AI 讲解 → 动手实验 → 选择题测试 → 错题归因 → 间隔复习 → 解锁下一章
```

建议每周完成 1 个主章节；如果一周时间较少，可以只完成章节的核心任务，AI
会根据掌握度把章节拆成更小的日任务。每章测试建议至少 80% 正确率，连续两次
低于 80% 时自动生成补课章节。
