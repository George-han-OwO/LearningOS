# 02 · 人生信息库驱动的个性化学习

## 可以使用的信息

人生信息库可以帮助 AI 做四类事情：

- 选择更容易理解的例子：把抽象概率连接到学习、工作或用户明确关注的项目。
- 安排节奏：根据用户明确记录的可用时间调整每天任务量。
- 发现目标：把课程项目连接到用户已经声明的长期目标。
- 识别复习需求：结合章节成绩、错题、实验结果和长期未复习内容。

## 不应自动推断的事情

AI 不应从邮件或生活记录推断敏感人格、健康、财务、家庭关系或政治立场，也不
应把这些内容自动写进训练数据。除非用户明确授权，课程题目只使用抽象字段和
经过最小化处理的事实。

## 推荐数据结构

```json
{
  "learning_profile": {
    "current_topics": ["AP Statistics"],
    "not_started": ["calculus", "linear algebra"],
    "weekly_minutes": 240,
    "preferred_explanations": ["analogy", "diagram", "code"],
    "declared_goals": ["understand LLMs", "build a small AI"]
  },
  "mastery": {
    "statistics.descriptive": 0.35,
    "math.calculus.derivative": 0.0
  },
  "privacy": {
    "allow_personal_examples": true,
    "allow_raw_email_in_prompts": false,
    "allow_external_training": false
  }
}
```

## 掌握度的教学版模型

不把“连续打卡”当成掌握度。一个简单的教学估计可以是：

```text
mastery = 0.35 × 最近测试 + 0.25 × 延迟测试
        + 0.25 × 动手实验 + 0.15 × 自己解释
```

实际产品可以再加入时间衰减和错题类型，但必须允许用户查看“为什么 AI 认为我
需要复习”。这套公式是教学简化，不是心理测量学结论。
