# 飞书录音日记

Journal → 录音日记以日期光盘展示每日摘要，左右滑动或箭头循环浏览，点击光盘阅读。右上角同步按钮重新读取服务器笔记。

沿用 `/api/feishu/<userId>/webhook` 和现有 webhook 验证。桥接需发送 `recording_id`、带时区的 `created_at`、`title` 与 `transcript`。只发送录音 ID 的飞书事件不会自动取得音频或转写文本。

后端按账号当前选择的 DeepSeek / Codex 生成每段录音摘要，然后按北京时间日期汇编为当天摘要合集（没有额外的跨录音二次 AI 综合，也不必等到晚上）。每日记录存入 SQLite notes，并写到 `data/obsidian-vault/<userId>/Recording Daily/`。重复 recording_id 更新原记录；桥接必须保持录音 ID 和录制日期稳定。无 ID 时使用转写文本 SHA-256 作为回退标识。每日 Markdown 使用固定日期标题和 source ID，重复回调覆盖同一文件。

更新客户端和实际服务器上的后端后生效；Claw 只负责部署。旧版单段笔记保持原样，不自动推断录制日期或回填每日光盘。可用原始录音 ID、日期和转写重新投递需要归档的历史记录。
