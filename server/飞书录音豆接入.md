# 飞书录音豆 → AILearningOS

## 当前接入方式

AILearningOS 已提供服务器端接收入口：

```text
POST /api/feishu/{userId}/webhook
```

入口接收飞书录音完成事件，或接收飞书/中间桥接程序得到的转写文本。服务端会：

1. 调用已配置的 DeepSeek；
2. 生成中文和英文摘要；
3. 抽取学习要点、待处理事项和英语词汇；
4. 写入今日 Note；
5. 写入 `server/data/obsidian-vault/{userId}`；
6. 将抽取到的英语词汇加入 Word Bank。

服务端不会把原始录音内容作为长期笔记保存，只保存摘要、学习要点和必要的词汇证据。

## 飞书侧配置

在飞书开放平台创建自建应用，订阅录音完成事件。视频会议录音完成事件通常使用：

```text
vc.meeting.recording_ready_v1
```

飞书开放平台提供事件回调、视频会议和语音识别等开放能力，具体权限需要以当前租户后台显示的版本为准：

- https://open.feishu.cn/
- https://open.feishu.cn/document/server-docs

把事件回调地址设置为：

```text
https://你的域名/api/feishu/1/webhook
```

服务器需要区分两种 token。建议设置以下环境变量：

```text
FEISHU_WEBHOOK_TOKEN=一串随机的长字符串
FEISHU_VERIFICATION_TOKEN=飞书开放平台显示的验证 token
```

`FEISHU_VERIFICATION_TOKEN` 用于飞书开放平台的 URL 验证，以及原生事件中的飞书 token；`FEISHU_WEBHOOK_TOKEN` 用于转写桥接程序调用 AILearningOS。两者不要混用。

桥接程序请求必须携带以下任意一种形式的 `FEISHU_WEBHOOK_TOKEN`：

```http
X-Feishu-Webhook-Token: 一串随机的长字符串
```

或 JSON（仅适合受信任的桥接程序）：

```json
{"token":"一串随机的长字符串"}
```

## 为什么需要转写桥

飞书的录音完成事件主要用于通知“录音已经可以获取”，事件本身不一定直接包含完整转写文本。生产部署建议使用一个小型桥接程序完成：

```text
飞书录音完成事件
        ↓
桥接程序用飞书权限获取录音/转写结果
        ↓
POST /api/feishu/1/webhook
        ↓
AILearningOS 摘要、入 Word Bank、写入 Obsidian
```

桥接程序向 AILearningOS 发送的最小请求示例：

```json
{
  "recording_id": "feishu-recording-id",
  "title": "统计课录音",
  "created_at": "2026-08-27T12:00:00Z",
  "transcript": "这里放飞书转写后的文本"
}
```

如果只发送原生 `recording_ready` 事件而没有 `transcript`，AILearningOS 会确认收到事件，但返回 `accepted: false`，等待桥接程序带着转写文本重试。原生飞书事件中的 token 可能位于 `header.token`，服务端 v2 已兼容读取。

飞书后台完成 URL 验证，只能证明公网地址可达；必须再用带 `transcript` 的请求验证 DeepSeek、今日 Note、Word Bank 和 Obsidian 是否都成功。

## 本地测试

```powershell
$payload = @{
  recording_id = 'demo-recording-001'
  title = 'AP Statistics 录音测试'
  created_at = (Get-Date).ToUniversalTime().ToString('o')
  transcript = '今天我们学习 sample、population 和 variable。请记住样本是总体的一部分。'
} | ConvertTo-Json

Invoke-RestMethod `
  -Method Post `
  -Uri 'http://127.0.0.1:8080/api/feishu/1/webhook' `
  -ContentType 'application/json' `
  -Body $payload
```

测试成功后检查：

```text
D:\AI-自学OS\server\data\obsidian-vault\1
```

然后运行：

```powershell
openclaw wiki compile
openclaw wiki search "AP Statistics"
```
