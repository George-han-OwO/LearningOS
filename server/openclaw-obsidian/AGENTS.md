# AILearningOS Obsidian vault

This directory is a shared knowledge vault generated by AILearningOS. It is
mounted into OpenClaw at `/home/node/.openclaw/wiki/main`.

## Operating rules

- Treat Markdown frontmatter as provenance. Preserve `source`, `source_id`,
  `updated`, `ai_generated`, and `tags` when editing a generated note.
- `source` identifies the origin (`chatgpt`, `outlook`, `qq`, or `manual`).
  `source_id` is the idempotency key; do not create a second note for the same
  source id.
- Keep personal email and conversation content private. Do not copy vault
  content into public replies, external services, logs, or commits unless the
  user explicitly asks for it.
- Prefer adding human corrections in a clearly marked section below the
  generated summary. Do not silently rewrite the original English/Chinese
  summary.
- Use `openclaw wiki search`, `openclaw wiki get`, and `openclaw wiki lint` for
  knowledge operations. Run `openclaw wiki compile` after restoring or making
  substantial external edits.
- The server may write new files while OpenClaw is running. Re-read the note
  before editing it and keep writes atomic where possible.
- Never store API keys, OAuth tokens, passwords, or mailbox credentials in this
  vault.
