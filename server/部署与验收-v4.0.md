# v4.0：Canvas 待办、Codex OSS 会话与五小时额度自动回切

构建标识：`2026-09-08-canvas-codex-autoreturn-v4.0`。

## 系统边界

开发机不是实际后端服务器。手机通过 HTTPS 调用部署在另一台电脑上的 AILearningOS 后端；Codex App Server、账号隔离登录态、额度读取和 OSS 会话读取都在后端服务器运行。Claw 只是独立的更新机器人，不参与登录、请求路由或额度消耗。

## 本版内容

1. Canvas 课程作业成为主页信息源，按提交状态分入“今日待办”和“已完成”。Canvas token 仍只在后端按 LearningOS 账号加密保存。
2. Codex OSS 历史显式请求 `cli`、`vscode`、`exec`、`appServer`、子代理和 `unknown` 来源，避免 App Server 创建的会话被默认过滤。只同步工作目录最后一级名为 `OSS` 的会话，只保存用户与助手文本，不保存 reasoning、命令或工具输出。
3. 设置页显示 Codex 短周期/长周期已用比例、剩余比例和重置时间。
4. 新增用户级“额度恢复后自动切回 Codex”开关。开启且 DeepSeek Key 已配置时，Codex 因额度/429 失败会临时把该用户路由切到 DeepSeek并重试；后端记录官方 `resetsAt`，到期确认短周期额度大于 0 后再自动切回 Codex。登录失败、网络失败、模型错误不会触发此规则。
5. SQLite schema 升级到 15，新增 `auto_return_to_codex` 与 `codex_resume_at`。原登录态、Canvas、DeepSeek 密钥、单词和笔记不删除。

## 部署

使用 `AILearningOS-server-windows-x64-v4.0.zip`，目标仍是实际服务器目录，例如 `D:\AI-自学OS\server`。

1. 在实际服务器核对正在运行的 PID、端口、计划任务动作和运行账号；不要照抄历史 PID。
2. 暂停自动拉起并正常停止已核实的旧服务。完整备份 SQLite、WAL/SHM、旧程序和启动脚本；保留 `data`、`AILO_SECRETS_MASTER_KEY`、代理与 Cloudflare 配置。
3. 覆盖新包的 `bin\server.exe`、`bin\sqlite3.dll`、`lib\sqlite3.dll`、`start-server.ps1`。不要清空 `data`，不要更换主密钥。
4. 使用运行后端的同一 Windows 账号确认原生 `codex.exe` 可用，再由 `start-server.ps1` 启动。不要把 `codex.ps1` 当作可执行文件，也不要让 Claw 登录 ChatGPT。
5. 更新计划任务使其指向启动脚本，并保留原账号、环境变量和代理。

## 验收

先验证实际服务器本机，再验证公网：

```text
GET /health -> 200 OK
GET /version -> build = 2026-09-08-canvas-codex-autoreturn-v4.0
GET /version -> codex_gateway_enabled = true
```

随后使用一个测试 LearningOS 账号完成以下验收：

1. Canvas 已连接时，主页出现未提交作业和已完成作业。
2. ChatGPT-Codex 显示短周期（通常 300 分钟）和长周期额度。
3. 创建或打开工作目录最后一级为 `OSS` 的 Codex 会话，调用历史接口确认能读取标题和用户/助手文本；检查响应不含 reasoning、命令文本或认证信息。
4. 打开自动回切开关。额度未耗尽时保持 Codex；只有模拟/真实返回明确的 quota、usage limit 或 429 时才临时切 DeepSeek，并写入 `codex_resume_at`。
5. 到重置时间后，后端确认剩余额度大于 0，`provider` 自动回到 `codex`，`codex_resume_at` 清空。手机刷新设置后应显示 Codex。
6. 关闭自动回切后，任何失败都不应自动改变路线。

仅 `/version` 正常只能证明服务已更新，不能证明某个账号的 ChatGPT 授权、额度或 OSS 会话实际可读。最终线上确认必须在另一台真实服务器完成，且不得输出 session token、Canvas token 或 `auth.json`。

### 从开发电脑做脱敏验收

部署完成并在手机端登录 LearningOS、ChatGPT-Codex 后，可在开发电脑的
PowerShell 中临时设置以下两个进程级环境变量：

```powershell
$env:AILO_SERVER_URL = 'https://os.example.com'
$env:AILO_SESSION_TOKEN = '<手机当前 LearningOS 设备会话 Bearer>'
dart run tool/verify_remote_server.dart
```

该工具只读取 `/health`、`/version`、Codex 账号状态、额度和 `OSS` 历史统计；
不会输出会话令牌、账号标识或聊天正文。用完后关闭当前 PowerShell，或移除这两个
进程级变量。不要把 Bearer 写入仓库、部署包、命令历史截图或 Claw 的 memory。
