# v4.1：Codex 登录防抖与五秒静默恢复

构建标识：`2026-09-08-codex-login-debounce-v4.1`。

## 系统边界

开发电脑不是实际后端服务器。手机通过 HTTPS 调用另一台电脑上的 AILearningOS 后端；`codex app-server`、账号隔离登录态、额度读取和 OSS 会话读取全部在后端运行。Claw 只是独立的部署机器人，不参与登录、请求路由或额度消耗。

## 本版内容

1. 移动端底栏改为无圆角的 `Home / Words / Journal / Setting` 四个英文入口，Setting 直接位于底栏。
2. 同一 LearningOS 用户已有未完成 Codex 登录时再次请求登录，后端取消该用户近期全部未完成流程并返回 HTTP `429`。
3. 取消后进入五秒静默期；期间的新登录请求会重新开始五秒计时，连续五秒无请求后才允许创建一个新的设备码流程。
4. 已登录用户按用户 ID 隔离；匿名登录按客户端安全存储的随机安装标识隔离。服务器只保存安装标识的 SHA-256 摘要，不记录原值。
5. SQLite schema 升级到 16，新增登录请求作用域与 `codex_login_guards` 静默状态表。静默期可跨服务重启恢复，旧登录态、Canvas、DeepSeek 密钥、单词和笔记不删除。
6. 保留 v4.0 的 Canvas 首页待办、Codex OSS 会话来源读取、用量显示和五小时额度自动回切。

## 防抖规则

```text
首次创建登录
    -> 返回设备码，状态 pending

同一发起方再次创建
    -> account/login/cancel 取消其全部 pending 登录
    -> HTTP 429 + code=codex_login_quiet_period
    -> quiet period = 5 秒

静默期内再次创建
    -> 不启动 codex app-server 登录
    -> 静默截止时间重置为“本次请求 + 5 秒”

连续 5 秒无请求
    -> 允许创建唯一的新登录
```

取消范围只包括同一发起方尚未完成的登录流程；不会退出已经绑定成功的 Codex 会话，不会取消 AI 生成、OSS 同步或其他用户的登录。

## 部署

使用 `AILearningOS-server-windows-x64-v4.1.zip`，目标是实际服务器目录，例如 `D:\AI-自学OS\server`。

1. 在实际服务器核对当前 `server.exe` 的绝对路径、PID、8080 端口归属、计划任务动作和运行账号，不要照抄历史 PID。
2. 暂停自动拉起并正常停止已核实的旧服务。完整备份 SQLite、WAL/SHM、旧程序和启动脚本；保留 `data`、`AILO_SECRETS_MASTER_KEY`、代理及 Cloudflare 配置。
3. 覆盖新包中的 `bin\server.exe`、`bin\sqlite3.dll`、`lib\sqlite3.dll` 与 `start-server.ps1`。不要清空 `data`，不要更换主密钥。
4. 使用运行后端的同一 Windows 账号确认原生 `C:\codex\codex.exe` 可用，再通过 `start-server.ps1 -CodexCommand "C:\codex\codex.exe"` 启动。
5. 更新计划任务使其继续指向启动脚本。Claw 只部署文件，不登录 ChatGPT，不读取或保存用户授权信息。

```text
GET /health -> 200 OK
GET /version -> build = 2026-09-08-codex-login-debounce-v4.1
GET /version -> codex_gateway_enabled = true
GET /version -> codex_login_debounce = per-user-cancel-and-five-second-quiet-v1
```

## 登录防抖验收

使用一个专门的测试 LearningOS 账号：

1. 发起一次 ChatGPT-Codex 登录并保持设备码未完成。
2. 立即再次点击登录；应收到“登录过于频繁、已取消近期未完成登录、停止操作 5 秒”的提示。
3. 旧设备码即使随后授权，也不得绑定到 LearningOS 用户。
4. 五秒内再次点击应继续返回 HTTP `429`，并从最后一次点击重新计算五秒。
5. 连续五秒不操作后再次点击，应只创建一个新的设备码流程。
6. 使用另一个 LearningOS 用户同时登录，不应被第一个用户的取消或静默状态影响。
7. 在静默期内重启后端，重启后五秒限制仍应生效。
8. 已完成并绑定的旧 Codex 登录不应被退出，AI 路由、额度与 OSS 同步继续可用。

仅 `/version` 正常不能证明真实登录链路已通过。最终验收必须在另一台真实后端服务器进行，不得输出 LearningOS Bearer、Canvas token、ChatGPT token 或 `auth.json`。

## 脱敏远程验收

部署并登录后，可在开发电脑临时运行：

```powershell
$env:AILO_SERVER_URL = 'https://os.example.com'
$env:AILO_SESSION_TOKEN = '<测试账号的 LearningOS Bearer>'
dart run tool/verify_remote_server.dart
```

工具只输出健康、版本、登录状态、额度和 OSS 数量，不输出令牌、账号标识或对话正文。
