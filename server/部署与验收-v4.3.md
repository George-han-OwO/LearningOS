# v4.3：Evidence Pack 与学习记录隐私收口

构建标识：`2026-09-10-evidence-pack-privacy-v4.3`。

## 系统边界

手机通过 HTTPS 调用另一台电脑上的 AILearningOS 后端。Codex 进程、账号隔离登录态、SQLite、Canvas/飞书接入和 Obsidian 全部在那台后端电脑上。Claw 只是独立的部署/更新 AI，不参与登录、AI 路由、数据存储或额度消耗。

## 本版内容

1. v1.7.0 客户端在 Journal 内新增 Evidence Pack，索引 Journal、飞书录音和 Canvas 作业。
2. 证据显示来源、时间、类型、关联和项目/课程，支持 Learner / Coach / MEL 角色视图。
3. Daily / Weekly / Monthly 复盘先生成可编辑证据索引，用户确认后才保存为学生反思。
4. `GET/POST /api/notes/<userId>` 强制校验 Bearer 和账号 ID：未登录返回 401，跨账号返回 403。
5. `/api/users/credential` 不再向客户端返回密码哈希或盐，固定返回 410。
6. 保留 v4.2 的 Codex、DeepSeek、Canvas、飞书录音、OSS 会话和 Obsidian 能力。

## 部署

使用 `AILearningOS-server-windows-x64-v4.3.zip` 更新实际服务器（例如 `D:\AI-自学OS\server`）。

1. 核对真实 `server.exe`、PID、8080 监听归属、计划任务动作和运行账号。
2. 停止自动拉起并正常停止旧服务；完整备份 SQLite、WAL/SHM、旧程序和脚本。
3. 保留 `data`、`AILO_SECRETS_MASTER_KEY`、飞书 token、代理与 Cloudflare 配置。
4. 覆盖包内 `bin\server.exe`、两份 `sqlite3.dll` 和 `start-server.ps1`。
5. 用真实后端服务账号通过 `start-server.ps1 -CodexCommand "C:\codex\codex.exe"` 启动，并保持计划任务指向该脚本。

## 验收

```text
GET /health -> 200 OK
GET /version -> build = 2026-09-10-evidence-pack-privacy-v4.3
GET /version -> codex_gateway_enabled = true
GET /version -> evidence_pack = source-time-origin-role-review-v1
GET /version -> notes_authorization = bearer-owner-enforced-v1
```

再用两个隔离测试账号验收：

1. 账号 A 带自己 Bearer 读写 `/api/notes/A` 成功。
2. 匿名读取 `/api/notes/A` 返回 401。
3. 账号 B 使用自己 Bearer 读取 `/api/notes/A` 返回 403。
4. 客户端 Journal → Evidence Pack 能搜索真实 Canvas 作业、手动 Journal 与飞书录音摘要。
5. 切换 Coach/MEL 时，原始录音和未确认 AI 摘要不显示。
6. 创建 Weekly Review，修改草稿后点击确认，Journal 中出现“学生确认”来源的新记录。

部署时不得把 LearningOS Bearer、Canvas/飞书 token、DeepSeek Key、ChatGPT token、`auth.json` 或完整私密记录写入日志。
